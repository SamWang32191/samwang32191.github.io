# 產品準則 (Product Guidelines)

## 語氣與氛圍 (Tone & Voice)
- **效率優先 (High Efficiency)**：所有介面元素應直覺且反應迅速。
- **簡潔直接**：不使用多餘的裝飾性文字，專注於管理功能。

## 設計原則 (Design Principles)
- **資訊密度極大化**：採用密集列表佈局，確保在單一視野內能看到盡可能多的專案。
- **隨動式體驗 (Adaptive)**：支援系統級深淺模式自動切換，並確保在兩種模式下皆有良好的可讀性。
- **微動導引**：使用細微的微互動（Subtle Micro-interactions）來提示用戶當前操作狀態（如 Hover 或搜尋過濾），但不影響效能。

## UI 組件規範 (UI Component Standards)
- **列表項 (List Item)**：保持高度緊湊，包含必要的 GitHub 圖示、專案名稱及快速跳轉連結。
- **搜尋框 (Search Bar)**：始終固定於易於觸及的位置，支援即時過濾。
