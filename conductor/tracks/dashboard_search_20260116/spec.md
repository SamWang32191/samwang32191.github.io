# Specification: 優化專案卡片列表與實作即時搜尋功能

## 背景 (Background)
目前的專案展示方式為傳統卡片流，當專案數量較多時，管理與查找變得困難。為了提升管理效率，我們需要將 UI 轉化為更高密度的 Dashboard 列表風格，並加入即時搜尋功能。

## 目標 (Goals)
- 實作一個緊湊的專案列表 (Compact List)，能一次展示更多專案。
- 在頁面頂部實作搜尋框，支援即時過濾功能。
- 支援系統級深淺模式適應。

## 用戶實例 (User Stories)
- **身為使用者**，我希望能一次看到我的所有 GitHub Pages 專案，以便快速掃描功能。
- **身為使用者**，我希望能透過輸入關鍵字立即過濾列表，以便在數十個專案中找到特定的那一個。
- **身為使用者**，我希望能點擊列表項快速跳轉至專案網頁或 GitHub 倉庫。

## 技術要求 (Technical Requirements)
- 使用 React 狀態管理搜尋關鍵字。
- 搜尋邏輯應對專案名稱及 Topics 進行模糊匹配。
- 列表佈局應在移動端保持響應式（但在桌面端追求高密度）。
- 必須包含單元測試以驗證搜尋過濾邏輯。

## 設計要求 (Design Requirements)
- 遵循儀表板 (Dashboard) 風格。
- 列表項應包含：GitHub 圖示、專案名稱、標籤 (Topics)、最後更新時間。
- 微互動效果：Hover 列表項時應有細微的視覺反饋。
