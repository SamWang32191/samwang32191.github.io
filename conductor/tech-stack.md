# 技術棧 (Tech Stack)

## 前端框架 (Frontend Framework)
- **Next.js (App Router)**：利用伺服器元件（Server Components）提供卓越的效能與開發體驗。

## 語言與類型 (Language & Typing)
- **TypeScript**：確保代碼強類型安全，減少運行時錯誤。

## 樣式 (Styling)
- **Tailwind CSS v4**：使用新一代內容優先的 CSS 框架進行快速、一致的排盤設計，支援 Dashboard 的密集佈局。

## API 整合 (API Integration)
- **Octokit**：官方 GitHub API 用戶端，用於穩定獲取 GitHub Pages 專案列表。

## 測試 (Testing)
- **Vitest**：高效能的單元測試工具。
- **Testing Library**：確保 UI 元件的行為符合預期。
